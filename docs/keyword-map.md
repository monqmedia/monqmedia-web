# Mapa de palabras clave

Una consulta principal por URL para evitar canibalización. Antes de crear o
reescribir contenido, comprobar aquí que la consulta no está ya asignada.
Fuentes: Search Console (exportación quincenal en Drive) y Keyword Planner.

Notas de datos (23/10/2026):
- Nicho B2B con volumen muy bajo: "leads placas solares", "marketing fotovoltaica",
  "agencia marketing placas solares", "conseguir clientes placas solares" salen sin
  volumen medible en Keyword Planner → estrategia long-tail + GEO.
- Familia "publicidad placas solares / publicidad para paneles solares /
  paneles solares anuncios / publicidad de paneles solares": ~50/mes cada una,
  competencia baja.
- Search Console (3 meses): clics casi solo de marca; "generar leads instaladores"
  pos. 42; "leads de aerotermia" pos. 8,5.
